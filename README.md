# C++ 贪吃蛇游戏

## 项目概述

这是一个使用C++编写的命令行贪吃蛇游戏，采用了面向对象的设计方法。游戏具有经典的贪吃蛇玩法，包括移动控制、食物收集、分数计算和游戏结束判定等功能。

## 功能特性

### 核心功能
- 🐍 蛇的移动与控制（WASD）
- 🍎 随机食物生成
- 📊 实时分数显示
- ⏰ 游戏速度控制
- 💀 碰撞检测（墙壁和自身）
- 🎮 游戏暂停/继续功能
- 🔄 游戏重新开始选项

### 高级功能
- 🎯 不同难度级别
- 🏆 最高分记录系统
- 🎨 彩色界面显示
- 📝 游戏状态保存/加载
- 🔧 可配置的游戏设置

## 技术实现

### 开发环境
- **语言**: C++11及以上
- **编译器**: MinGW
- **平台**: Windows

### 依赖项
- **标准库**: `<iostream>`, `<vector>`, `<conio.h>` (Windows) 或 `<ncurses.h>` (Linux/macOS)
- **其他**: 可能需要平台特定的终端处理库

## 安装与编译

### Windows 系统
1. 确保已安装MinGW和Visual Studio Code
2. 使用git克隆或下载项目文件
3. 使用CMake插件点击生成编译
4. 编译后的.exe文件在.\build\bin\GreedySnake.exe，双击即可开始游戏

## 游戏操作说明

### 控制键
- **W**: 向上移动
- **S**: 向下移动
- **A**: 向左移动
- **D**: 向右移动
- **Q**: 退出游戏

### 游戏规则
1. 控制蛇头移动（屏幕上显示的"◉"）吃食物（屏幕上显示的"◈"）
2. 每吃一个食物，蛇身（屏幕上显示的"◯"）长度增加，得分增加
3. 撞到墙壁或自身会导致游戏结束
4. 游戏难度随分数增加而提高（蛇移动速度加快）

## 自定义配置

### 修改游戏设置
在 `GameManager.h` 或配置文件中可以调整以下参数：

```cpp
// 游戏区域大小
const int row = 20;
const int col = 20;

// 游戏速度（毫秒）
std::chrono::milliseconds autoMoveInterval(std::chrono::milliseconds(1000))
```

### 添加新功能
1. **新的食物类型**：继承Food类并实现特殊效果

3. **多人模式**：创建多个Snake实例并处理交互

## 常见问题解答

### Q: 游戏界面排版不规则
A: 建议使用Windows终端来运行游戏，可在Microsoft Store中搜索Windows Terminal下载安装。

### Q: 游戏无法编译
A: 确保已安装所有必要的开发库，并且编译器支持C++11标准。


### Q: 游戏显示乱码
A: 确保终端支持UTF-8编码，并使用了等宽字体。

### Q: 如何调整游戏难度？
A: 修改GameManager类中的autoMoveInterval参数或在游戏选项菜单中选则难度级别。
